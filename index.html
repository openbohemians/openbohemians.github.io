Oyl ↗

The optimized YAML library

C11

A fast, minimal YAML 1.2 parser and emitter with SIMD acceleration. A small C core, with bindings for Crystal, Rust, and Go. The Go bindings support fast YAML-to-JSON conversion for Kubernetes workflows.

How we’re building this

A little structure.
Room to grow.

Open Bohemians is a small, founder-led initiative. Our aim is shared stewardship that helps software outlast any one maintainer.

Responsibility

Make the care visible.

Named maintainers, honest project status, and clear expectations about what is supported.

Continuity

Leave a way forward.

Readable documentation, thoughtful releases, and enough context for the next person to pick up the work.

Participation

Keep the door open.

Welcome useful contributions, from a careful bug report to someone ready to share maintenance.
